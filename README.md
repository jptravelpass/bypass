# ByPass Tokyo

도쿄 지하철·JR 경로, 요금, 교통 패스 추천 앱.

## 안드로이드

**[⬇ ByPass.apk 받기](https://github.com/jptravelpass/bypass/releases/latest/download/ByPass.apk)** (안드로이드 8.0 이상)

1. 위 링크로 APK 를 받아요.
2. 받은 파일을 눌러요. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**.
3. **설치**. Play 프로텍트 경고가 나오면 **세부정보 더보기 → 무시하고 설치**.

업데이트도 같은 링크에서 받아 설치하면 돼요. 저장한 정보는 그대로 남아요.

## 아이폰

1. **사파리**에서 [bypass-tokyo.vercel.app](https://bypass-tokyo.vercel.app) 을 열어요.
2. **공유** 버튼 → **홈 화면에 추가** → **추가**.
